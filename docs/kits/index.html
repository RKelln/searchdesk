Build a Search Desk feature

Everything you need is below. There is nothing to install.

  1. Press Copy this kit under the one you want.
  2. Paste it into a free AI chat, in a new chat.
  3. Save the file it gives you as features/<id>.js. Plain text, not a word-processor file.
  4. Open features/list.js and add the id to Desk.features.
  5. Reload Search Desk and put #selftest at the end of the address.
